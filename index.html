Clinical Rationale

This system implements a structured diagnostic decision tree for pulpal and apical classification based on AAE-aligned diagnostic principles.

Decision Engine

The CDS utilizes deterministic rule-based logic incorporating:

  • Endo Ice Test response
  • Lingering pain assessment
  • Caries extension status
  • Percussion test findings
  • Swelling and sinus tract presence
  • Radiographic findings

Informatics Architecture

The application integrates:

  • Structured clinical input model
  • Rule-based diagnostic inference engine
  • CDT code mapping layer
  • FHIR-style structured JSON output
  • Cloud deployment via Hugging Face Spaces
